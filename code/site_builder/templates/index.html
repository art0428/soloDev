四步開始

前三步只做一次，第四步是之後每天的工作方式。

一、安裝 skill

下載 skill 檔，在 Claude 桌面版的 Skills 設定上傳；用命令列版就解壓到 ~/.claude/skills/。

裝過舊的 project-init 請先移除，兩個不要同時裝。

二、做好原型

做一份 index_v1.html，所有畫面、狀態與欄位都要畫出來。沒有原型不要開工，AI 會自己猜。

開工前要準備

本機先用假登入就能跑起來，接真實登入與部署時才需要後兩項。

項目版本或說明
Claude Code桌面版或命令列版皆可
Node.js22，範本會鎖定版本
pnpm10，沒有時初始化腳本會改用 corepack
PostgreSQL本機一個開發用資料庫
MCC 帳號MCC 是管理者中心的登入平台，接真實登入時才需要測試憑證
Docker 與 GCP選配，要部署到正式機時才需要

改版通知

每次改版都會發一個 GitHub Release，附上新的 skill 檔與更新說明。到 GitHub repo 右上角按 Watch，選 Custom，勾 Releases，之後每發一版 GitHub 會寄 email 給你。

已開工的專案不受新版影響，新專案才用新範本。
